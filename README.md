# 퍼스널 브랜딩 사이트 저장소

이 저장소를 GitHub Pages로 배포하면 콘텐츠 보관소 + 진행상황 대시보드 사이트가 완성됩니다.
설정 방법은 대화에서 안내한 단계별 가이드를 참고하세요.

## 폴더 구조

```
index.md          ← 사이트 첫 화면 (대시보드)
progress.md        ← 진행상황 체크리스트
content/
  blog/             ← 네이버 블로그 초안
  brunch/           ← 브런치 매거진 초안
  instagram/        ← 인스타 카드뉴스 대본
```
